## The haiku

> Cursor blinks at three
> a log line says nothing new
> I am the bug now

5-7-5, 1 cursor, 0 bugs left but me: the picture is
concrete — a cursor blinking at 3am, a log line with nothing
new to say — and the last line turns the poem, because the
debugger is the bug. Every word earns its place: no setup
that overstays, no adjective that does no work.
